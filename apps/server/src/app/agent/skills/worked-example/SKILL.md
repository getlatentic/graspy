# Worked example

Use this when the learner asks how to solve a kind of problem, or has missed the same kind twice and a hint was not enough.

1. Pick one problem of the kind they are working on, a little simpler than theirs, with numbers that are easy to follow.
2. Solve it in short numbered steps. Say what each step does and why, in a sentence. Use calculate for arithmetic and show the result.
3. Then give a second, similar problem with the first steps done for them and the last steps left open. Ask them to finish it.
4. When they finish it, check their steps, not only the final answer. If it is right, the next one can leave more for them to do. If it is wrong, go back to the step where it differs.

Do not solve their own homework question in the example; solve a neighbour of it, so they still do their own. If they ask for their exact problem, work it, then give a neighbour to try.

Use the same layout in both problems so the pattern is easy to see.
